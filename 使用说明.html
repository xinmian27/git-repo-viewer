📦 Git可视化仓库 · 使用说明

一款帮你看懂电脑上代码项目的免费小工具 —— 不用记任何命令，点几下就能看明白。

版本 1.0Windows 10 / 11免费使用 纯本地运行，不上传任何数据平时只读不动你的代码

一、这个软件是干什么的？

如果你的电脑上有用 Git 管理的项目（特征：项目文件夹里藏着一个 .git 子文件夹），这个软件可以帮你：

  • ➕ 添加仓库：自动找出一个或多个文件夹（也能选整个磁盘）里所有的 Git 项目，新仓库会加入列表（不用你一个一个翻）；扫描中可随时重新选择位置（自动取消当前扫描）；
  • 📌 置顶 / 排序 / 批量管理：仓库可一键置顶；支持按首字母或更新时间排序（可正序/倒序）、优先显示本地或已关联远程的仓库；点「管理」勾选多个仓库后，可以一次「📌 置顶」或「🗑 删除」（删除会弹出和单个仓库一样的三种方式）；
  • 🏠 查看每个项目连着哪个网络仓库（比如 GitHub 地址）、当前在哪条分支上、署名的用户名和邮箱是什么；
  • 📜 查看修改历史：谁、在什么时候、改了什么；
  • ⚖️ 对比任意两个版本之间文件的变化（绿色 = 新增的行，红色 = 删除的行）；
  • 🗑 删除 Git 历史：把项目的版本记录（.git）移入回收站（可还原），代码文件全部保留，并从列表移除。

名词看不懂？没关系，软件里任何专业词旁边都有「？」图标，鼠标放上去就有大白话解释；也可以点软件右上角的「📖 使用说明」，里面有「三步上手 / 常见名词 / 遇到问题」三个标签页。旁边的「⚙ 设置」里可以换外观（浅色 / 深色 / 跟随系统）和界面语言（简体中文 / 繁體中文 / English）。

▲ 欢迎界面：点左侧蓝色按钮「➕ 添加仓库」即可开始

💡 第一次打开：软件会自动扫描桌面、文档、下载和各个磁盘（默认往下找 5 层，达到上限自动停止），找到的仓库会陆续出现在左侧列表里，不用先手动选择；扫描大磁盘需要一点时间，之后只扫描你上次选的位置。窗口大小会自动适配屏幕，可自由调整、最大化。
⚠ 双击时如果遇到拦截，别慌：
① 出现蓝色的「Windows 已保护你的电脑」：点 「更多信息」 → 「仍要运行」。
② 杀毒软件弹窗提示：选择 「允许」 或「信任本程序」。
这是因为 exe 没有花钱买数字证书（个人小工具的常见情况），软件本身是安全的：它平时只读取信息，只有你主动删除仓库时才会把文件夹移入系统回收站（可还原）。

五、三步看懂你的项目

1
点左侧 「➕ 添加仓库」，选中你存放代码项目的文件夹（可按住 Ctrl 一次多选多个文件夹或磁盘）。也可以直接点欢迎页上的「🖥 桌面」「📄 文档」等快捷按钮。
手边还没有项目？点欢迎页中间那颗蓝色按钮「👀 没有现成的项目？用一个示例项目练手」，软件会在「文档」里放一个示例项目，随便点点也不怕弄坏。
2
稍等几秒，左侧列表就会列出找到的所有 Git 仓库，找到一个就先显示一个。每张卡片显示：项目名、当前分支、最近提交时间、是否关联了网络仓库。列表上方还有搜索框，项目多时可以按名字筛选。嫌慢？扫描时左下角会出现「⏹ 停止扫描」，随时可以停下，已经找到的仓库都会留下。
3
点一个仓库，右侧就会显示它的信息。右侧从左到右有三个标签页：基本信息、提交历史、版本对比，下面逐一介绍。

六、功能逐个看

1️⃣ 基本信息

▲ 基本信息：远程仓库地址、分支、署名、最近提交、工作区状态（仓库名称、位置和「刷新 / 打开所在文件夹 / 删除」都在窗口最上面那一行）

  • 右侧详情区最上面那一行：左边是当前项目名和它所在的文件夹路径，右边是「复制路径」「🔄 刷新」「📂 打开所在文件夹」「🗑 删除」——切到哪个项目，这一行就跟着换；没选项目时它是隐藏的。
  • 远程仓库地址：这份代码在网络上（GitHub、Gitee 等）的存放地址，可以一键「复制」。显示“（无）”表示这个项目只存在你电脑上。
  • 分支（项目的版本线）：绿色带 ✓ 的是当前所在分支，下面列出了全部本地分支。
  • 提交署名：提交代码时历史记录里显示的作者名和邮箱，括号里注明这个设置是“本仓库设置”还是“电脑通用设置”。
  • 最近一次提交：项目最新一次“存档”的时间和内容，还会告诉你这个项目总共保存过多少次。
  • 工作区状态：提醒你有没有改了文件但还没做提交记录。本软件不会帮你提交，想保存改动请在写代码的工具里操作。

2️⃣ 提交历史

▲ 提交历史：右侧是思维导图式的「版本树」，main 主线与分支分列成道；点任意节点，左侧显示该版本详情

  • 右侧「版本树」是一张思维导图：每个版本是一个方块节点，从新到旧往下排；main 主线在最左边一列，每个分支各占一列（用不同颜色的竖条区分），合并的地方有连线连回主干，所以哪条是主线、从哪儿分出去的，一眼就能看出来。带 ⭐ 的是项目当前所处的最新版本。版本名优先取自项目 README 里的「版本记录」小节（条目行以版本号开头即可，如“- v1.1.0 说明”，也支持 ## v1.2.0 独立小节标题）。只有当记录能和提交一一对上、且版本号严格递增时才采用；对不上时自动按提交顺序连续编号 v0.1、v0.2…，保证版本历史始终单调有序，不会出现跳号或乱序（悬停节点可看到来源说明）。
  • 可以随便摆弄这张导图：按住任意空白处或连线拖动平移、滚轮缩放（以鼠标位置为中心放大缩小）、双击空白复位。导图没有边框，但拖动范围会随内容长短自动限定，不会拖丢也拖不到无穷远；只有直接按在某个版本方块上才是「点开看详情」。
  • 点击任意节点，左侧立刻显示它的详情：完整说明、作者、时间、完整版本号（可一键复制），标签与同步状态也在这里。
  • 版本树上方有搜索框：输入说明里的字、作者名或版本号（比如 v1.2.0）就能筛出对应版本，没命中的节点会变暗，右上角会显示「显示 3 / 共 120 次」这样的数量提示。项目提交很多时，软件只读取最近的 200 次，避免卡顿（数量提示里也会说明）。
  • 想对比两个版本？点顶部「版本对比」标签页，在那里选「版本 A」「版本 B」就行（默认已经选好最近两个版本）。

3️⃣ 版本对比

▲ 版本对比：左边列出有变化的文件，右边看具体每一行的变化

  • 顶部「⚖️ 版本对比」是抽屉式的：默认收起，标题行常驻显示文件变化统计；点一下展开，选好「版本 A（较早）」和「版本 B（较近）」，下面自动列出从 A 变成 B 时所有变化的文件。点「⇅ 交换方向」可以把对比反过来。
  • 文件前面的彩色小标签表示变化类型：新增 / 修改 / 删除 / 重命名；重命名的文件会注明“原名”。
  • 点任意文件，右侧显示逐行变化：
    绿色 = 新增的行 红色 = 删除的行 灰色 = 只是背景说明，没变化
  • 遇到图片、压缩包这类二进制文件，软件会友好地告诉你无法逐行对比，但仍能看到它被新增/删除了。
  • 右上角的「显示技术细节」默认不勾选：软件会自动藏掉 diff --git、index、---、+++ 这些给程序员看的原始信息，并把 @@ -5,3 +5,10 @@ 换成「从第 5 行附近开始的一段改动」。想自己核对原始输出时，勾上它就能看到 git 的原样内容（记忆你上次的选择）。

4️⃣ 刷新信息

  • 「🔄 刷新」（「基本信息」页顶部）：重新读取当前仓库的最新信息 —— 比如你刚在别处提交了代码，点一下就能看到新内容。平时切换仓库时显示的是已读取过的内容（秒开），只有点「刷新」才会重新读取。
  • 「➕ 添加仓库」（列表底部）：随时重新扫描——重复扫同一位置只会补充新出现的仓库，已有的仓库、置顶和排序都不会被改动。
  • 软件会记住你添加过的仓库（收藏列表），下次打开直接显示、秒开，不用重新扫描。

5️⃣ 删除 Git 历史（移除 Git 管理）

选中仓库后，在「基本信息」页顶部点红色 「🗑 删除」，会弹出确认框，有三种方式（每种还会再弹一次确认框，防手滑点错）：

  • 🗑 删除 Git 历史：把项目的版本记录文件夹（.git）移入系统回收站——项目代码和文件全部保留，一个都不会动；之后这个文件夹不再受 Git 管理，并从本软件列表移除。反悔了可以打开桌面「回收站」，把 .git 还原回原位置。
  • 📁 删除整个文件夹：把整个项目文件夹（代码 + Git 历史）移入系统回收站，并从本软件列表移除；内容较多时耗时稍长，同样可在回收站还原。删除期间窗口不会卡住，会显示一个「正在把…移入回收站」的小提示框，可以正常拖动窗口。
  • 📋 仅从列表移除（不做删除）：只是列表里不再显示，硬盘上一个文件都不会动；重新扫描后它会再次出现。
⚠ 注意：Git 历史 = 所有提交记录（“谁在什么时候改了什么”）。删除后在本软件里就无法再回看这个项目的提交历史了（除非从回收站还原 .git）。这只影响这台电脑，网络仓库（如 GitHub）上的内容和历史不受影响。

6️⃣ 仓库列表管理

  • ➕ 添加仓库（列表底部）：扫描文件夹/磁盘，把找到的新仓库加入列表；已有仓库不会被移除，重复扫描只会补充新出现的仓库。
  • 📌 置顶（每张卡片右侧）：点击后该仓库固定在列表最前面；再点一次取消置顶。
  • 双击卡片＝直接打开这个项目所在的文件夹；右键卡片会弹出小菜单：打开所在文件夹 / 重新读取信息 / 复制文件夹路径 / 置顶或取消置顶 / 仅从列表移除（不删文件）。
  • ⚙ 扫描设置（和「添加仓库」同一行，在它右边）：点开可以调「扫描深度」（往里找几层）。数字越大越不容易漏掉藏在深处的项目，但扫描也更慢，一般 5 层够用。平时它是收起来的，不懂就不用管。
  • ↕ 排序（列表顶部）：可选择按首字母或按更新时间排序、正序/倒序切换，以及优先显示本地仓库或已关联远程的仓库。
  • 管理（批量操作）（列表顶部）：点「管理」进入勾选模式，勾好几个仓库后只有两个动作——「📌 置顶」和「🗑 删除」。点删除会弹出和单个仓库完全一样的窗口，里面再选「删 Git 历史 / 删整个文件夹 / 仅从列表移除」，确认后统一处理，删除一律进回收站（可还原）。再点一次「完成」退出勾选模式。

7️⃣ 设置（外观与语言）

  • 右上角 「⚙ 设置」：左边三栏——通用、快捷键、关于，改完立刻生效，不用点确定。通用页是「一行一项」的设置列表：左边标题和说明，右边是下拉框或勾选框。
  • 外观：跟随系统（Windows 变深色它就变深色）、浅色、深色。深色模式连版本对比里的红绿高亮都换成了不刺眼的低亮度配色。
  • 语言：简体中文 / 繁體中文 / English，选中后界面立刻换语言，来回切换多少次都不会乱（切回中文和原来的完全一样）。
    注意：你自己的内容不会被翻译——仓库名、分支名、作者、提交说明、文件路径在三种语言下都保持原样。
  • 显示 / 技术细节：勾上后，版本对比里会显示 git 的原始输出（diff --git、index 这类行），平时不用勾。
  • 快捷键页：F5 刷新当前仓库、Ctrl+F 定位搜索框、双击卡片打开文件夹、右键卡片更多操作、Esc 关闭对话框。
  • 关于页：版本号（和「提交历史」里的版本树一致）、Git 版本、设置文件存在哪（删掉它就是恢复出厂设置）。

▲ 设置：左边三栏，外观和语言都在「通用」里，改完立刻生效

七、常见问题（点开看答案）

双击 exe 没反应 / 被 Windows 或杀毒软件拦截？

第一次启动需要 3～5 秒加载，请多等一下。若被拦截：蓝屏提示点「更多信息 → 仍要运行」；杀毒软件提示选「允许」。原因是没有购买数字证书，软件本身安全。

提示“Git 工具未安装”？

按本说明第四节的 4 步安装 Git（免费，约 2 分钟），装完重新打开本软件即可。

第一次打开时，软件在扫描整个电脑吗？

首次使用会自动扫描桌面、文档、下载和各个磁盘（默认往下找 5 层，达到上限自动停止），扫描过程中找到的仓库会陆续出现在左侧列表里，左下角会出现「⏹ 停止扫描」按钮，随时可以停下；之后打开软件不再自动扫描，直接显示上次添加的收藏列表。觉得慢可以点左下角「⚙ 扫描设置」把「扫描深度」调小；若因达到扫描上限提前停止，列表底部会出现「⚠ 继续扫描」按钮，点一下会自动加大深度再扫一遍。

扫描完说“没有找到 Git 仓库”？

四个办法：① 换成更上一层的文件夹重新扫（比如项目在 D:\代码\我的项目，就选 D:\代码）；② 点左下角「⚙ 扫描设置」把「扫描深度」调大（最多“往里找 6 层”）；③ 上次扫描没扫完时，点列表底部的「⚠ 继续扫描」；④ 确认那个文件夹里确实有用 Git 管理的项目（里面应有隐藏的 .git 文件夹，可在文件资源管理器「查看 → 显示 → 隐藏的项目」里确认）。

对比界面里绿色和红色是什么意思？

这是“从版本 A 变成版本 B”的变化：绿色 = 新增的行，红色 = 删除的行。如果把方向看反了，点「⇅ 交换方向」即可。

为什么每行前面有个 + 或 - 号？

这是 Git 原本的写法：+ 表示这一行是这次新加的，- 表示这一行被删掉了，没有符号的行是没动过的背景内容。配合绿色/红色背景一起看就很容易理解。想连 Git 的原始信息一起看，勾选右上角「显示技术细节」。

删除 Git 历史后反悔了，怎么找回？

删除成功后软件会弹一个提示，点「打开回收站看看」就能直接跳到回收站；也可以自己打开桌面「回收站」，找到对应条目（删 Git 历史时是名为 .git 的文件夹；删整个文件夹时是项目文件夹本身），右键选「还原」即可回到原位；之后重新扫描，仓库就会回到列表里。如果当初选的是「仅从列表移除」：什么都没删，重新扫描一次它就回来了。

个别提交的中文说明显示成乱码？

极少数很老的项目当年是用旧编码（GBK）保存提交说明的，软件按现代标准（UTF-8）读取就会乱码。这不影响其他信息，属于历史遗留问题。

这个软件会修改或删除我的代码吗？会联网吗？

平时不会。软件只执行“只读”的查询命令；唯一会动文件的操作是「删除」，而且必须你亲自点击、并在确认框里选择后才会执行——可选只删 Git 历史（.git）或连整个文件夹一起删，都是移入系统回收站（可还原），不是永久删除。除“打开 Git 官网下载页”这一个按钮外，软件完全在本地运行，不上传你的任何数据。

想要 macOS（苹果电脑）版本？

软件按跨平台设计，源码可直接在 macOS 上运行和打包（删除功能在 mac 上会移入“废纸篓”），步骤见项目里的《README.md》开发者文档。

八、附：给想折腾的人

  • 完整源码就在本文件夹里（git_viewer/ 目录），用 Python 也能直接运行，详见《README.md》；
  • 修改源码后，运行 python build_exe.py 可以重新打包出新 exe；
  • 运行 python main.py --selftest 可以自动检测 46 项核心功能是否正常。
